# pokemon-barcode

iPhone Safariの背面カメラでJAN/EANバーコードをライブ認識する、家族向けの私的プロトタイプです。

検索エンジン向けの除外設定はありますが、アクセス制御はありません。URLを知っている人は利用できます。

## 仕様

- Quagga2 1.12.1
- EAN-13 / EAN-8をライブ認識
- EANチェックデジットを検証
- 同じコードを1.6秒以内に3回検出したときだけ確定
- SHA-256で同じバーコードを常に同じNo.1〜1025のポケモンへ変換
- SHA-256の別領域を使い、同じバーコードでは常に同じ色違い判定（2%）
- PokeAPIからポケモンの通常画像・色違い画像、日本語名、No.、タイプを取得して表示
- CSS/JavaScriptのみのGET演出（ボール投げ→1・2・3→「つかまえた！」）
- GETしたポケモンを`pokemonId`単位で端末内の`localStorage`へ保存
- GET済み・回数・色違い回数・進捗が分かる1025匹の図鑑
- カメラ映像はサーバーへ送信しない
- GET記録も外部サーバーやGoogle Sheetsへは送信しない

## 使い方

1. iPhoneのSafariでGitHub PagesのURLを開く
2. 「カメラをはじめる」を押す
3. カメラの利用を許可する
4. 商品バーコードを黄色い枠に入れる

カメラ利用にはHTTPSが必要です。GitHub PagesはHTTPSで配信されます。
